## 📝 Project Description
In this project, we developed a complete AI system, starting from raw data preprocessing all the way to deployment in a real-time application. The main goal was to design a Convolutional Neural Network (CNN) capable of recognizing letters and words from hand gesture images in sign language. We then integrated this model with a machine vision system to continuously translate sign language movements into audio output in real time.
